# Security policy

Development foundation, version `0.1.0-dev`; no production security certification.
Please report suspected vulnerabilities privately through GitHub private vulnerability
reporting when enabled. Do not attach credentials, tokens, private keys, session IDs,
MFA seeds or recovery codes to issues or public pull requests.

See docs/security-model.md for the supported boundaries and residual risks. Security
fixes require regression evidence and review before a release. No release is published
as part of this foundation mission.
